# claude_backup_viewer

A simple graphical program (no need to install additional packages, just standard Python)
To view the backup/export file taken from Claude.ai

File required: the same ZIP that you downloaded from Settings > Privacy > Export data
(including conversations.json, memories.json, users.json and the projects/ folder)

Run:
python3 claude_backup_viewer.py

Then click on the "Open Export (zip or folder)" option from the File menu and select the extracted
zip file or folder.

برای مرور فایل بکاپ/Export گرفته‌شده از Claude.ai

(شامل conversations.json ، memories.json ، users.json و پوشه projects/)

اجرا:
    python3 claude_backup_viewer.py

سپس از منوی File گزینه "Open Export (zip or folder)" را بزن و فایل
zip یا پوشه‌ی استخراج‌شده را انتخاب کن.

یک بکاپ ریدر برای خواندن فایل های بکاپ هوش مصنوعی کلاد که توسط این برنامه میتونید فایل های بکاپ رو بصورت محیط گرافیکی مشاهده کنید
میتونید ازش بعنوان نسخه آفلاین فایل های خودتان در کلاد هم ازش استفاده کنید
نوشته شده به زبان پایتون
